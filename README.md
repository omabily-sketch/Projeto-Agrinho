# Este projeto é uma plataforma web interativa desenvolvida com HTML5 semântico, CSS3 e JavaScript puro, cujo objetivo é educar o público sobre a conexão entre campo, cidade e sustentabilidade através da Agricultura 4.0. O site apresenta o papel de inovações como drones e inteligência artificial na preservação ambiental e engaja o usuário de forma prática por meio de um quiz automatizado em tempo real. Com um design limpo e totalmente responsivo, a aplicação utiliza a própria tecnologia de programação para conscientizar as novas gerações e demonstrar como a inovação digital constrói um futuro mais consciente e integrado para o Agrinho 2026.Projeto-Agrinho
